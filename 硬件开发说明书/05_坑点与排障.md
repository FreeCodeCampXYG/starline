# 坑点与排障

| 现象/误区 | 先检查什么 | 安全处理 |
| --- | --- | --- |
| 手册说 XJWB03，板背印 LJWB76 | 实物丝印、PCB 版本、套件照片和原理图修订是否对应 | 暂停套用 GPIO 表，先取得硬件版本映射 |
| 音频模块名 KIT/Core 不一致 | 模块丝印、VB701N 版本、排线 pin-1 | 不用名称相似推断接口相同 |
| 只看 BSP 就接线 | 当前 mainboard 原理图、接口 pinout、装配版次 | BSP 是固件映射，不证明板上连线 |
| GPIO 输出 3.3 V，外设 5 V 工作 | 外设 `VIH`、`VDD` 和 level-shifter | WS2812 5 V 时 VIH=3.5 V，3.3 V 不保证；选择电平转换并量测 |
| MPU6050 设备扫描不到 | VCC/GND、SDA/SCL、上拉电压、7-bit 地址、原始 WHO_AM_I | 当前模块图显示 AD0 低；先读原始值，不先删身份检查 |
| MPU6050 新版 ID 不同 | 模块版本/芯片丝印、WHO_AM_I 原值、寄存器读回 | 供应方说明不是官方兼容认证；保存证据并对照寄存器语义 |
| 摄像头没有画面 | FPC 正反、VCC/2.8 V、MCLK 24 MHz、PWDN、SCCB、1-bit SPI 格式 | 当前固件相机宏为 0；启用前释放 GPIO4/GPIO8 复用 |
| 相机硬件需要 XCLK 但软件没有 XCLK | 当前转接板是否有 X1 24 MHz、当前装配是否与图一致 | 原理图与 BSP 注释口径有冲突，先核实实板时钟源 |
| 舵机抖动、主控重启或顶住不动 | 舵机型号、堵转电流、电源跌落、PWM 脉宽上下界、机械止挡 | 外部供电，共地，限幅脉宽；不要用 GPIO 供电 |
| 振动模块不动作 | 模块是否含 MOS、VCC 范围、IN 有效电平、GND 共地 | 不把裸马达与带驱动的三针模块混为一类 |
| 摄像头和舵机/MPU 同时启用失败 | 当前 GPIO4/GPIO8 资源复用 | 选一种外设或改板级设计，并先更新资源账本 |
| 烧录后功能和 README 对不上 | 当前构建宏、sdkconfig、分区 CSV 和实际镜像 | 对照提交，不使用陈旧手册默认值 |
| 第一次全量构建很慢 | 仓库含大型 SDK、模型和托管组件 | 分析可用 partial clone；完整构建需完整检出依赖与模型资源 |
| 对外分享时复制了仓库密钥 | README/历史版本/日志/截图 | 不复述、不再传播；项目负责人轮换密钥并清理历史暴露面 |

## 排查顺序

`身份与连接器方向 -> 电源轨 -> 共地/逻辑电平 -> 信号方向/协议 -> GPIO 冲突 -> 固件宏与分区 -> 驱动/业务逻辑`。

这个顺序能避免把供电或接线问题误判为软件缺陷。每次只改变一个变量，并保留测量条件和原始日志。
