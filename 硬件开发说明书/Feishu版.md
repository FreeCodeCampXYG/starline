# 灵机一动硬件开发说明书：从认板到做出第一个作品

## 这份说明书的定位

这份资料把 SDK、上手手册、模块图纸、器件规格书和配件图片交叉整理，面向第一次做硬件作品的人。它不是主板原理图，也不替代当前批次的 BOM、PCB 版本和实测记录。

证据标签：
- **器件/原理图已确认**：所给模块原理图或数据手册直接支持。
- **固件声明**：当前 Git 提交里的宏、BSP 和配置值。
- **资料声称**：使用手册、供应方说明或商品页，尚未由当前批次实测复核。
- **待确认**：缺少原理图、版本映射或实物测量。

## 1. 先弄清自己拿到哪块板

Gitee SDK README 和快速手册称主控底板为 `XJWB03-DevKIT-V1`，音频板为 `LJX40-Audio-KIT-V1`。但主板背面实物照片和飞书配件图写着 `LJWB76-DevKIT-V1`；飞书中的音频板照片描述为 `LJX40-Audio-Core-V1`。这些名称可能是套件名、板名或不同修订，目前没有原理图/BOM/版本映射证明它们是同一电气设计。

## 2. 软件项目分几层

仓库是 ESP32-S3 固件 SDK 示例，而不是完整主板 PCB 工程。`apps/main/main.c` 负责启动编排；`peripheral/bsp_*.c/.h` 负责驱动外设；`cloud/`、`voice/`、`agent/` 和 `lj_components/` 负责联网、音频、语音会话和业务插件；底层来自 `qumios-dev/`、`components/` 和 `esp-idf/`。

本次 Git 提交为 `89020f5e04bf777ae1672b8f3d320bc6e0ef3e0c`，日期 `2026-10-23`。`esp-idf/` 和 `qumios-dev/` 在 Git 树中是普通目录，不是 submodule；手册中的 submodule 更新步骤与当前结构不符。

当前 `qm_config.h` 的播放、闹钟、姿态识别宏为 1，摄像头测试和番茄钟宏为 0；MPU6050、舵机、振动和 WS2812 的初始化示例在 `main.c` 中被注释。README/手册的默认状态与当前配置有差异，功能状态要以本次构建实际使用的宏为准。

## 3. 动手前先掌握四个硬件概念

### 电源和电流

GPIO 是控制/数据脚，不是电源脚。主控供电、传感器逻辑电源、舵机/马达负载电源可能属于不同电源域。外设启动或堵转时会拉高电流，导致电源跌落、串口乱码或主控重启。主板完整电源原理图尚未提供，不能从外观推定哪路电源能带多大负载。

### 共地和逻辑电平

当两个模块用电压电平表示信号时，通常需要共同的 GND 参考；但先检查原理图，不要跨隔离电源随意并地。ESP32-S3 GPIO 不是 5 V tolerant。把外设输出接入主控前，要核对双方的高低门限和电源轨。

### 总线和方向

I2C 的 SDA/SCL 是开漏总线，需要上拉；多个模块共总线时要检查地址和并联后的上拉阻值。UART 至少是 TX 接对端 RX、RX 接对端 TX 并共地。PWM 的脉宽是控制信号，不会替舵机提供电源。WS2812 是按 DIN/DOUT 串接的数据链，不是每颗灯一个 GPIO。

### GPIO 复用

同一个 GPIO 可能被多个外设复用。固件当前选择不是板子所有能力的完整清单；还要看 USB/JTAG/UART/Flash/PSRAM 等芯片限制和板上真实走线。

## 4. 先从最容易理解的模块开始

### MPU6050：看懂 I2C 与板载稳压

模块原理图显示 5 V 输入经 3.3 V LDO 给芯片供电，SDA/SCL 通过 4.7 kΩ 上拉到 3.3 V，AD0 被拉低。当前 BSP 使用 I2C0、GPIO8 SDA、GPIO9 SCL 和地址 `0x68`；但主程序中 MPU 初始化目前被注释。

![MPU6050 模块原理图](@./硬件开发说明书/assets/mpu6050-module-schematic.png)

新版兼容说明称芯片 ID 有差异并建议去掉检测；该说明没有给新芯片完整型号和寄存器兼容证据。遇到问题先记录 I2C 地址、原始 WHO_AM_I、模块丝印和读回寄存器，不要先删身份校验。

### BF3901 摄像头：看懂供电、时钟与数据接口

规格图标明 BF3901、24-pin FPC、AVDD 2.7-3.0 V、DOVDD 1.7-3.0 V。2026-10-11 摄像头转接板原理图包含 2.8 V 稳压器、24 MHz 振荡器和去耦网络。

![BF3901 模组引脚与供电规格](@./硬件开发说明书/assets/bf3901-camera-module-pinout.png)

![摄像头转接板原理图](@./硬件开发说明书/assets/camera-adapter-schematic.png)

当前 BSP 把传感器按 1-bit SPI 采集：VSYNC 接 CS、PCLK 接 SCLK、D0 接 DATA0，HREF/D1 不接。相机当前宏关闭；映射为 GPIO21 SDA、GPIO47 SCL、GPIO4 CS、GPIO13 PCLK、GPIO8 DATA0、GPIO41 PWDN。GPIO4 与舵机、GPIO8 与 MPU6050 有冲突。转接板画有 24 MHz X1，但 BSP 注释称模组自带时钟，具体实物时钟来源仍需核验。

### 舵机：控制脉冲与负载电流分离

所给参数页同时包含 MG90 和 TS90；配件照片描述为 MG90S。MG90 参数页列 4.8-6 V、500-2500 us、中点 1500 us、6 V 堵转电流约 860 mA ±10%。当前 BSP 使用 500-2400 us、中位 1450 us、50 Hz。型号和标定值有差异；先外部供电、限幅测试，再按实物标定，不能让舵机撞机械止挡。

![MG90 参数页](@./硬件开发说明书/assets/servo-mg90-spec.png)

### 振动模块：不要把模块和裸马达混为一类

规格页显示模块有 VCC/GND/IN，工作 3.0-5.3 V、额定 5 V，最大工作电流 60 mA、启动电流 90 mA，并说明集成 MOS 驱动。BSP 注释则描述外置三极管/MOS。GPIO5 在固件中高电平触发，但当前模块版本和有效极性要以实物核验。GPIO 不可直接带裸马达。

![振动模块规格与接口](@./硬件开发说明书/assets/vibrator-module-spec.png)

### WS2812：先检查数据门限，再追颜色

当前 BSP 用 GPIO1 驱动 8 颗 WS2812，数据顺序为 GRB。资料注释建议 5 V 供电、DIN 串 330 Ω、供电端并 100 uF 以上电容；主板和灯板装配图未提供，因此实际装配值仍待核。

![WS2812 输入门限](@./硬件开发说明书/assets/ws2812-electrical-limits.png)

该数据手册给出的 `VIH=0.7×VDD`。VDD=5 V 时需要至少 3.5 V 的高电平，ESP32-S3 的 3.3 V 输出不在该保证范围内。使用满足门限的电平转换器并检查波形，比靠近距离或“偶尔能亮”更可靠。

## 5. 当前固件的资源冲突

- GPIO4：舵机 PWM / 摄像头 VSYNC→CS。
- GPIO8：MPU6050 SDA / 摄像头 DATA0。
- GPIO1：WS2812 数据；GPIO5：振动模块控制输入。
- GPIO9：MPU6050 SCL；GPIO21/47：相机 I2C；GPIO13：相机 PCLK。
- GPIO38/39/40：VB701N 流控/RX/TX；GPIO43/44：UART0 日志/CLI。
- GPIO14：应用层低电平保持 3 秒触发配网解绑/清除；不要与照片中的 EN 按钮混为一谈。

该表是当前 SDK/BSP 的声明，不是主板原理图确认的网络表。ESP32-S3 的 GPIO 复用/启动 strap/USB/JTAG/Flash/PSRAM 约束也需要一起检查。

## 6. 做第一个作品的建议路线

1. 拍照记录板卡丝印、PCB 版本和接口方向。
2. 画电源树和资源表，给每个结论标证据等级。
3. 先测电源，再逐个模块接入；一次只改变一个变量。
4. I2C 传感器先扫地址、读身份寄存器；不要跳过原始数据。
5. 舵机/马达用独立额定电源，测启动时压降，再接逻辑信号。
6. WS2812 先测单颗、低亮度和电平转换，再扩展到灯圈。
7. 摄像头先核 FPC 方向、2.8 V、24 MHz、引脚复用，再打开相机配置。
8. 集成后检查宏、分区、GPIO 冲突、内存和总电流；保存代码提交与测试记录。

## 7. 需要硬件负责人确认的事项

- XJWB03 / LJWB76 是否是同一 PCB 或不同修订；LJX40 Audio KIT/Core 的版本映射。
- 主板原理图、BOM、Gerber、装配/DNP、供电树，以及 BOOT/EN/GPIO14 的实际连接。
- MG90S/TS90 舵机的准确型号与固件脉宽标定。
- 振动模块的当前 PCB 版次、IN 极性与实际板载驱动。
- 摄像头转接板的 24 MHz 时钟是否实装、VCC 的供电来源和实测电平。
- 新版 MPU 模块准确芯片型号、WHO_AM_I 原值和寄存器兼容验证。
- WS2812 灯圈的电阻/电容实装值和 3.3 V 数据电平验证。
